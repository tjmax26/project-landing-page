# project-landing-page


This is a landing page project built as part of The Odin Project curriculum.

## What I Used
- HTML5 semantic elements
- CSS Flexbox for layout
- Google Fonts (Roboto)
- Embedded images

## What I Learnt
This project helped me practice and reinforce my knowledge of HTML and CSS,
including flexbox, embedding images, working with fonts, and structuring a 
clean and responsive landing page.
